# جرد المحل — تطبيق أندرويد

الكود كله في `www/index.html` (هو نفسه نسخة المتصفح). مشروع أندرويد (Capacitor 8) موجود في `android/`.

## بناء ملف APK (مرة واحدة)

1. ثبّت **Android Studio** من https://developer.android.com/studio (يأتي معه Android SDK و Java المناسب).
2. افتح Android Studio ← **Open** ← اختر المجلد `app/android`.
3. انتظر حتى ينتهي "Gradle Sync" (أول مرة يحمّل مكتبات، قد يأخذ عدة دقائق).
4. من القائمة: **Build ← Generate App Bundles or APKs ← Generate APKs**.
5. عند الانتهاء اضغط **locate** — الملف في:
   `app/android/app/build/outputs/apk/debug/app-debug.apk`
6. انقل الملف للهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## بعد أي تعديل على `www/index.html`

```
cd app
npm run sync     # ينسخ التعديلات إلى مشروع أندرويد
npm run web      # يحدّث نسخة المتصفح "جرد-المحل.html" في المجلد الرئيسي
```
ثم أعد البناء من Android Studio (الخطوة 4).

## ملاحظات
- الكاميرا: أول مرة يطلب التطبيق إذن الكاميرا — اضغط "سماح".
- البيانات محفوظة داخل التطبيق على الهاتف. حذف التطبيق أو "مسح بيانات التطبيق" يحذفها — احفظ نسخة احتياطية من الإعدادات.
- بيانات التطبيق منفصلة عن بيانات نسخة المتصفح؛ للنقل بينهما استخدم حفظ/استرجاع النسخة الاحتياطية.
- `android.overridePathCheck=true` في `gradle.properties` ضروري لأن مسار المجلد يحتوي أحرف عربية.
